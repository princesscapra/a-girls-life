# Methodologie MVP

Ce prototype est un simulateur pedagogique, non un outil de prediction individuelle.

## Principes

- Perimetre principal: France.
- Pas de recommandations medicales ou juridiques individualisees.
- Les probabilites annuelles sont initialisees pour le MVP puis doivent etre recalees.
- Chaque evenement affiche sa source et la date de collecte.
- Le ton est volontairement factuel et sobre.

## Limites actuelles

- Certaines probabilites sont des proxies annuels de demarrage.
- L'agregation de sources heterogenes (ONG + institutions) necessite une normalisation.
- Les effets cumulatifs sont encore simplifies.

## Prochaine etape data
